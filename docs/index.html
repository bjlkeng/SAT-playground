SAT Playground

Iterative SAT solvers, benchmarked against real baselines.

This repository builds Boolean SAT solvers one iteration at a time in Rust, keeping each solver self-contained and measurable. The main figure below uses the latest available SAT Competition 2025 Medium run for each in-repo solver that has one, alongside reference solvers in a distinct color, to show how quickly each solver accumulates solved instances over time.
