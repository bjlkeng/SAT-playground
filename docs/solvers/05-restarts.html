05 restarts

This iteration layers a simple CDCL restart policy on top of 04's watched-literal + EVSIDS core. Conflicts are grouped into Luby-sized windows, the solver periodically jumps back to level 0 while keeping learned clauses, and saved variable polarities are reused so the restarted search does not forget its recent bias completely.

What It Implements

  • The same watched-literal propagation, conflict analysis, learned clauses, and EVSIDS-driven branch queue from 04.
  • A Luby restart schedule that counts conflicts inside a restart window and marks a pending restart once the current budget is exhausted.
  • Backtracking to decision level 0 on restart while keeping learned clauses and root-level implications intact.
  • Phase saving so each variable remembers its most recent polarity and reuses it the next time it is chosen as a branch variable.

High-Level Pseudocode

initialize watched-literal CDCL state
initialize EVSIDS scores, branch heap, saved polarities
restart_budget = luby(1) * restart_unit

loop:
  conflict = propagate_over_trail()

  if conflict exists:
    if decision_level == 0:
      return UNSAT

    learned_clause, backjump_level, analyzed_vars = analyze_conflict(conflict)
    bump activity for analyzed_vars
    add learned_clause to the database
    backtrack(backjump_level)
    enqueue asserting literal
    conflicts_in_window += 1
    if conflicts_in_window == restart_budget:
      pending_restart = true
    continue

  if every variable is assigned:
    return SAT

  if pending_restart:
    backtrack(0)
    advance Luby window
    pending_restart = false

  variable = highest-activity unassigned variable from heap
  decide using saved polarity(variable)

Code-Level Optimization Diffs

The README has the longer history. These are the implementation changes that best capture how `05` differs from `04` in the current code.

Pending-Restart Scheduler

Restarts are deliberately decoupled from the propagation path: conflicts mark a pending restart, and the actual jump to level 0 happens before the next decision. 

- continue search from the current decision stack indefinitely
+ count conflicts inside a Luby-sized restart window
+ set a pending-restart flag and backtrack to level 0 before the next branch

Saved Phase Reuse

Branch selection now carries a small amount of polarity memory across backtracks and restarts instead of always branching with the default sign. 

- always branch with the same default literal polarity
+ store the last assigned polarity for each variable
+ reuse that saved phase when the variable is chosen again

Hot-Path Cleanup Around Restarts

The retained tuning changes in the README focus on keeping the new restart machinery cheap enough not to erase the gains from `04`. 

- repeated current-level reads and higher-overhead scratch clearing
+ cache current_level() inside enqueue()
+ clear analysis scratch arrays with write_bytes in the conflict path
