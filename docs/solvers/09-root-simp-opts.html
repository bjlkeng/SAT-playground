09 root-simp-opts

This iteration keeps 08's packed clause arena, learned-clause reduction, and relocating garbage collector, then adds a MiniSat-style root-level simplify() pass. The same step also cleans up several measured hot paths: branch-heap maintenance, watcher-list propagation, learned-clause reduction, and conflict-clause allocation.

What It Implements

  • The same watched-literal propagation, restarts, saved phases, EVSIDS branching, clause minimization, packed arena, proof streaming, learned-clause activity, and database reduction from 08.
  • A root-only simplification pass that propagates at decision level 0, detects root conflicts, removes satisfied original and learned clauses, and trims root-false literals from surviving original clauses.
  • A MiniSat-style simplification gate that skips full database scans unless root assignments changed or enough propagation work has happened since the previous pass.
  • An asymmetric learned-clause policy: satisfied learned clauses are deleted, but unsatisfied learned clauses are not strengthened by trimming root-false literals because profiling showed that change disrupted search quality.
  • Hot-path reductions in allocation and vector traffic across propagation, branch-heap cleanup, learned-clause reduction, and conflict analysis.

High-Level Pseudocode

initialize solver 08 state with packed clauses, watches, learned database, and proof stream
track live original and learned literal counts for simplify gating

loop:
  conflict = propagate()

  if conflict exists:
    if decision_level == 0:
      finalize UNSAT proof and return UNSAT

    learned_clause, backjump_level = analyze_conflict_into_reused_buffer(conflict)
    record learned_clause in the DRAT proof

    if learned_clause has one literal:
      backtrack to level 0
      enqueue the asserting literal without storing a watched learned unit
    else:
      add learned_clause to the arena and live learned list
      backtrack(backjump_level)
      enqueue learned_clause[0] with the new clause as reason
    continue

  if decision_level == 0:
    if simplify() finds a root conflict:
      finalize UNSAT proof and return UNSAT

  if learned database exceeds its budget:
    reduce learned clauses in place and collect arena garbage when waste is high

  if all variables are assigned:
    discard temporary proof output and return SAT

  branch on the highest-activity unassigned variable

Code-Level Optimization Diffs

The README has the full benchmark notes and the deeper diff against 08. These are the highest-signal implementation changes.

Root Simplification

The solver now revisits the clause database at decision level 0 to remove clauses already satisfied by root assignments and shrink original clauses that contain root-false literals. 

- keep original clauses permanently live after parsing
+ delete satisfied original and learned clauses at root
+ trim root-false literals from surviving original clauses

Branch Heap Cleanup

Assignments no longer mutate the branch heap immediately. Branch selection lazily skips assigned variables, and a root simplify pass rebuilds the heap with a bottom-up heapify. 

- remove every assigned variable from the heap during enqueue
+ leave assigned variables in place and skip them when branching
+ rebuild the heap in one bottom-up pass after simplification

Watcher Traffic

Propagation now compacts a scanned watch list in place, while clause detachment removes only the two watched entries with swap_remove. 

- move watchers through a separate retained vector and scratch buffer
+ compact the current watch list with read/write indices
+ detach deleted clauses from exactly their watched literals

Learned Clause Hot Paths

Learned-clause reduction sorts and filters the live learned list in place, and conflict analysis writes into a reusable scratch clause buffer. 

- clone learned-clause candidates during reduce_db()
- allocate a fresh learned-clause Vec per conflict
+ retain surviving learned clauses in place
+ move learned clauses through scratch_conflict_clause
