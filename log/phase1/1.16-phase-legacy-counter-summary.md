# Phase Legacy Counter Telemetry Fix

## Bead

- `SAT-playground-5b2.2.43`
- Phase 1 telemetry bug fix.

## Implementation

Default `SAT_PHASE=legacy` returned `saved_phase[var]` but incremented
`phase_initial_used`, which made default-profile JSON stats look like every
decision used the initial phase. The fix adds a dedicated `phase_legacy_used`
counter and leaves `phase_saved_used` for explicit saved-phase policy use and
`phase_initial_used` for true fallback to `initial_phase(var)`.

The new counter is emitted in `JSON_STATS` and `trace_full`, and README
documents the phase counter meanings.
